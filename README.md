## 🔭 Featured project

### [Ombuds](https://github.com/haliam/ombuds): governed AI claims-triage agent

An agentic system that triages EU261 flight-compensation claims.

- **Deterministic where it matters:** eligibility rules live in code, not in the model.
- **Human in the loop:** state-changing actions need explicit approval and run idempotently.
- **Grounded answers:** cited RAG over policy documents using PostgreSQL/pgvector, with tools exposed over MCP.
- **Safety and quality:** PII filtering, prompt-injection detection, and evals that track retrieval quality.
- **Documented decisions:** architecture docs and ADRs explain the trade-offs.

`Python` · `FastAPI` · `LangGraph` · `MCP` · `PostgreSQL / pgvector` · `Docker Compose`
